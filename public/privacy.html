Политика конфиденциальности и обработки технических данных

1. Общие положения
Настоящая Политика определяет порядок обработки технических данных пользователей сайта teacher-soft.ru (далее — Сайт). Сайт является некоммерческим, полностью бесплатным социальным проектом, созданным физическим лицом (далее — Администратор) для поддержки педагогического сообщества. Сайт не преследует коммерческих целей, не содержит рекламы и не осуществляет сбор пожертвований. Связь с Администратором осуществляется исключительно по электронной почте: teacher-soft.help@yandex.ru.

2. Отсутствие сбора персональных данных
Сайт не собирает, не хранит и не обрабатывает персональные данные в понимании ФЗ № 152 «О персональных данных» (такие как ФИО, номера телефонов, адреса личной электронной почты, паспортные данные). На Сайте полностью отсутствует регистрация, личные кабинеты и формы обратной связи.

3. Использование файлов cookie и систем веб-аналитики

Для обеспечения стабильной работы Сайта, анализа посещаемости и улучшения интерфейса на Сайте используется законный инструмент веб-аналитики Яндекс Метрика (ООО «ЯНДЕКС», РФ). Данный сервис в автоматическом режиме собирает обезличенные технические сведения:

  • Файлы cookie (куки);
  • Сведения о типе устройства, разрешении экрана, браузере и операционной системе;
  • Информация об источнике перехода на Сайт (поисковые системы, прямые ссылки);
  • Обезличенный IP-адрес (без привязки к конкретному лицу).

Данные собираются Яндекс Метрикой в обобщенном виде, используются Администратором только для статистики (мониторинга нагрузки на сервер) и не позволяют идентифицировать личность пользователя.

4. Права пользователей и отключение сбора

Сбор технических данных через Яндекс Метрику начинается автоматически при входе на Сайт. Пользователь имеет полное право в любой момент прекратить этот сбор, выполнив любое из действий:

  • Запретить сохранение файлов cookie в настройках своего интернет-браузера;
  • Использовать расширения-блокировщики (например, Яндекс Метрика Блокировщик);
  • Покинуть Сайт.
